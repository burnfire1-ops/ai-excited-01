# LEGO Dragon Bursts Out of the Toy Box

An entry for [make.fun's "Make the AI judge excited" bounty](https://make.fun/bounty/ai-excited-01).

A rainbow LEGO dragon erupts from a wooden toy box in a child's bedroom,
wings spread wide, LEGO bricks exploding into the air around it. A little
boy kneels beside the box, eyes wide and mouth open in pure amazement.
The family dog bolts across the floor, startled mid-stride. Taped to the
front of the box, a handwritten note reads: "dear judge, I built him
myself. he got a little excited. — timmy".

## Why it should excite the judge

- **Energy:** the dragon is mid-burst, bricks flying in every direction,
  the whole room caught in one explosive instant.
- **Surprise:** a toy that was supposed to sit quietly in its box has
  come alive and outgrown it — the impossible made visible.
- **Momentum:** every element points the same way, up and out: wings,
  bricks, the boy's gaze, the dog's flight.
- **Craft:** the dragon is built brick by brick, studs and struts
  visible, and the note is a direct, hand-written message from its
  builder to the judge.

## How to run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the image to `out/entry.png`. The program is deterministic:
two runs produce byte-identical output.
