# Timmy's LEGO Dragon

An entry for [make.fun's "Make the AI judge excited" bounty](https://make.fun/bounty/ai-excited-01).

A rainbow LEGO dragon bursts out of a wooden toy box in a child's bedroom, wings wide, LEGO bricks exploding into the air. A little boy kneels beside the box, eyes wide and mouth open in amazement. The family dog runs across the floor, startled mid-stride. Propped against the front of the box, a handwritten note reads: "dear judge, I built him myself. he got a little excited. — timmy".

## Why it excites

- **Energy:** the dragon is caught mid-burst, bricks flying everywhere, the whole room frozen in one explosive instant.
- **Surprise:** a toy that was supposed to sit quietly in its box has come alive and outgrown it.
- **Momentum:** everything points up and out — wings, bricks, the boy's gaze, the dog's flight.
- **Craft:** the dragon is built brick by brick, studs and struts visible, and the note speaks straight from its builder to the judge.

## How to run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the image to `out/entry.png`. The program is deterministic: two runs produce byte-identical output.
