# LEGO Dragon — ai-excited-01

A rainbow LEGO dragon bursts out of a wooden toy box in a child's bedroom,
bricks exploding into the air around it. A boy watches in amazement, a dog
dashes away in joyful surprise, and a handwritten note from "timmy" leans
against the box: *"dear judge, I built him myself. he got a little excited."*

## Why it should excite the judge

- **Energy:** the dragon is mid-burst, wings spread, bricks flying in every
  direction — a frozen moment of pure momentum, not a static pose.
- **Surprise:** a toy coming alive is impossible, and the scene plays it
  straight — a real bedroom, real light, a real kid's wonder.
- **Craft:** every scale of the dragon is a LEGO brick, and the explosion is
  made of the same bricks the dragon is built from. The note speaks directly
  to the judge, from the kid who built him.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies the bundled image to `out/entry.png` (byte-identical every run).
